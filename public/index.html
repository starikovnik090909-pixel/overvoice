Установка движка

Движок скачивается с Hugging Face автора VCClient. Файл большой (около 3 ГБ), нужно примерно 8 ГБ свободного места. Загрузку можно прервать, она продолжится с того же места.

Ещё понадобится бесплатный виртуальный аудиокабель VB-Cable (vb-audio.com/Cable): Overvoice отдаёт в него голос, а в OBS ты берёшь его как «Захват входящего звука».

Для Overdeck: POST /api/nv/voice {"slot": 0} включает голос, POST /api/nv/release останавливает.
