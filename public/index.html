Overvoiceнейроголос для стрима

Установка движка

Движок скачивается с Hugging Face автора VCClient. Файл большой (около 3 ГБ), нужно примерно 8 ГБ свободного места. Загрузку можно прервать, она продолжится с того же места.

Виртуальный аудиокабель VB-Cable

Overvoice отдаёт голос в кабель, а в OBS ты берёшь его как «Захват входящего звука». Кабель скачивается с официального сайта vb-audio.com, Windows спросит разрешение на установку драйвера.

Для Overdeck: POST /api/nv/voice {"slot": 0} включает голос, POST /api/nv/release останавливает.
